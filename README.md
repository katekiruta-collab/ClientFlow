# ClientFlow

Telegram Mini App для частных специалистов.

## Возможности MVP

- Dashboard специалиста
- Клиенты
- Записи
- Формирование счетов
- Telegram авторизация


## Структура

frontend/
- интерфейс Mini App


backend/
- API
- Telegram auth


## Запуск frontend

Открыть:

frontend/index.html


## Запуск backend

Перейти:

backend/

Установить зависимости:

npm install

Запуск:

npm start


## Environment

Создать файл:

.env


На основе:

.env.example


## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express

Telegram:
- Telegram WebApp SDK
